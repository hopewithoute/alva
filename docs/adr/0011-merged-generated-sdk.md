# 0011: Merged Generated SDK

The `alva` npm package is removed. Host apps get a complete, self-contained TypeScript SDK generated by `mix alva.codegen`. The codegen is the source of truth for frontend types and composables. The library becomes a codegen tool only — no runtime npm dependency.

The generated SDK imports `live_vue` directly (not through an abstraction layer). Composables use per-event methods for strict type safety and autocomplete, not generic event maps. The codegen trigger is a manual Mix task, not compile-time or file watcher.

**Considered Options:**
- Split (library + generated types) — rejected due to type drift and two sources of truth
- Generic composables — rejected in favor of per-event methods for better DX
- Compile-time/watcher generation — rejected for simplicity; Mix task is explicit

**Consequences:**
- Existing `alva` npm consumers must migrate to the generated SDK
- Bug fixes in composable logic require `mix alva.codegen` regeneration
- The library's `assets/js/` directory is removed or repurposed for codegen templates only
