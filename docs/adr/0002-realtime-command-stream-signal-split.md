# Realtime Command, Stream, and Signal Split

Phase 9 separates realtime communication into Commands, Streams, Signals, Route Subscriptions, and Page Projections. Commands remain Vue-to-server request/reply interactions; Streams are collection projections triggered only by Ash PubSub published event names via `on:` and applied with Phoenix stream operations that LiveVue 1.x delivers to Vue as stream diffs; Signals are semantic non-collection callbacks; and each LiveView page chooses which route topics to subscribe to and which resource projections to activate. Page-local Stream Query bindings may apply paginated command results to an active stream, but pagination behavior does not belong inside the resource-level Stream Block. This keeps collection synchronization on the LiveView/LiveVue stream path while avoiding a second client-side list reconciliation path through `ash.on()`.
