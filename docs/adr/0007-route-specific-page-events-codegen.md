# Route-Specific Codegen for Page Events

To provide complete type-safety for `page_events` in the frontend without risking global name collisions, we decided to implement route-specific codegen instead of relying on manual generics or a global registry. While Domain Events (which are globally unique) are generated into a single `events.ts` file, `page_events` are specific to individual LiveView pages. Generating them into a shared global dictionary would cause type collisions if two different LiveViews use the same event name (e.g., `"ui.submit"`) but expect different payload structures. By instructing the compiler to generate distinct type definition files per LiveView (e.g., `CustomerStorefront.events.ts`), frontend composables like `usePageEvent` can guarantee 100% strict type-safety. This approach explicitly trades increased compiler tooling complexity for a bulletproof, collision-free Developer Experience (DX).
