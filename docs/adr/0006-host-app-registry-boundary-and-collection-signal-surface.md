# Host App Registry Boundary And Collection Signal Surface

Alva will resolve its public command and projection surface from a Host App Registry Boundary keyed by `otp_app` and the host app's configured `ash_domains`, instead of page-scoped `domains:` input. Commands, Collections, Signals, code generation, and host-app compile-time uniqueness checks all flow through that application-wide boundary, while internal resource-local wiring such as Collection Source event keys stays local to the owning resource. As part of this simplification, Alva's public realtime surface is reduced to declarative Collection and Signal activation plus raw Phoenix PubSub escape hatches; page-scoped `domains:`, imperative `activate_stream/2`, and the `stream` DSL are removed because they preserve an obsolete runtime-selection model and blur the route-owned Collection contract.
